# OpenShape CAD

Ubuntu용 파라메트릭 3D CAD입니다. 화면 구성(응용프로그램 막대, 도구막대, 브라우저, 타임라인, ViewCube, 탐색 막대)과 사용 흐름은 Autodesk Fusion을 참고했고, 코드는 C#(Avalonia)과 Rust로 새로 작성했으며 형상 엔진은 OpenCASCADE, 스케치 구속조건 해석은 SolveSpace(libslvs)를 씁니다.
Autodesk의 코드, 아이콘, 리소스는 포함되어 있지 않으며 Autodesk와 관련이 없습니다. 아이콘은 모두 직접 그린 것이고, Wine·Windows 구성요소나 Autodesk 클라우드 없이 Ubuntu에서만 동작합니다.

## 설치

[Releases](../../releases)에서 `openshape_<버전>_amd64.deb`를 받아 설치합니다.

```
sudo apt install ./openshape_1.4.0_amd64.deb
```

저장소에서 직접 만든 경우 `sh packaging/install-deb.sh`로 설치하면 Ubuntu 24.04에서 apt의 부가 메시지("Download is performed unsandboxed...", "더 이상 필요하지 않습니다" 목록) 없이 설치됩니다.

### 시스템 정리 (Ubuntu 24.04)

`/opt/openshape/ubuntu-tidy.sh`(저장소: `tools/ubuntu-tidy.sh`)는 apt가 "더 이상 필요하지 않음"으로 표시한 패키지를 나눠 보여 줍니다. Wine이 쓰는 32비트 라이브러리와 apt 밖의 프로그램(예: 소스로 빌드한 ROS)이 쓰는 라이브러리·Python 모듈은 유지로 표시하고, 개발용 패키지와 아무것도 쓰지 않는 런타임만 제거합니다. 인자 없이 실행하면 보고만 하고, `--apply`로 적용, `--restore <목록>`으로 되돌립니다.

## 기능

개인용 Fusion처럼 작업공간이 네 개입니다. 왼쪽 위의 작업공간 버튼(디자인 ▾)으로 바꿉니다.

### 디자인
- 스케치: XY·XZ·YZ 평면(간격띄우기)과 본체의 평면 면 위에 선, 직사각형, 원, 3점 호, 다각형. 치수(거리·지름·각도)와 구속조건(일치·수평/수직·평행·직각·동일·고정·중간점·동심·접선·대칭), 그리면서 자동 구속, 점 끌기, 자르기
- 솔리드: 돌출, 회전, 로프트, 스윕, 상자·원통·구·원환, 코일, 파이프(속이 빈 파이프 포함), 구멍(단순·카운터보어·카운터싱크, 깊이·전체 관통, 드릴 끝 118°), 패턴, 대칭, 모깎기, 모따기, 쉘, 기울기(구배), 누르기/당기기, 결합, 본체 분할(원점 평면·평면인 면), 이동/복사, 축척
- 곡면: 곡면 돌출·회전·스윕·로프트, 패치, 스티치(닫히면 솔리드), 두껍게 / 판금: 플랜지, 모서리 플랜지, 판금 규칙, 평면 패턴(DXF) / 플라스틱: 리브, 보스
- 조립: 구성요소, 접합(강체·회전·슬라이더·원통형·핀-슬롯·평면형·볼)과 한계값 구동
- 검사: 측정, 단면 분석, 간섭(겹친 부분을 빨간색으로 표시), 무게 중심(물리 재질 밀도로 질량 계산)
- 파라메트릭 타임라인(편집·롤백·재생), 사용자 매개변수와 식
- 파일: `.osc` 디자인, STEP·IGES·STL·OBJ 열기/삽입, STEP·STL·OBJ·USD 내보내기, Isaac Sim용 물리·접합 USD
- IsaacSimLink 내장: Isaac Sim으로 형상(STEP) 또는 로봇(URDF: 링크·접합·질량·관성) 보내기, 저장할 때 자동 동기화

### 렌더
- 캔버스 내 렌더: 화면을 움직이지 않으면 경로 추적(Rust, 멀티스레드)으로 점점 선명해집니다
- 모양(재질): 금속(강철·알루미늄·황동·구리·크롬)과 플라스틱·고무·도장·목재·세라믹, 금속성과 거칠기 반영
- 장면 설정: 환경 프리셋(밝은 스튜디오·야외·어두운 스튜디오·해질녘), 태양 방위각·고도, 노출, 배경(환경/단색), 바닥 그림자와 반사
- 렌더링: HD~4K, 품질(16·64·256회 반복)을 골라 PNG로 저장

### 도면
- A4~A0 시트, KS 형식 제목 블록(제목·도면 번호·작성·검토·재료·날짜·척도·투상법), 3각법/1각법
- 기준 뷰(앞·위·오른쪽·뒤·아래·왼쪽·등각), 부모 뷰 주위를 클릭해 만드는 투영 뷰. 숨은선 제거(OpenCASCADE HLR), 숨은선·접선 모서리 표시, 원의 중심 표시
- 치수: 수평·수직(놓는 위치로 자동 결정), 정렬, 지름. 꼭짓점과 원 중심에 스냅. 텍스트 주석
- 뷰·치수 끌어 옮기기(투영 뷰는 투영선을 따라만 움직임), 실행 취소, 디자인 파일에 함께 저장
- 출력: PDF(글꼴 포함, 벡터), DXF(R12, 선 종류별 레이어), SVG

### 제조 (2.5축 밀링)
- 설정: 가공할 본체, 스톡 상자(옆·위 여유), 원점(스톡 상단 왼쪽 앞 모서리·상단 중심·모델 원점), 안전·후퇴 높이
- 작업: 페이스, 2D 포켓(바닥 면 선택, 안쪽에서 바깥으로), 2D 윤곽(면의 바깥 경계, 바닥 아래까지), 드릴(수직 구멍 자동 인식, 펙)
- 하향/상향 절삭, 최대 절삭 깊이, 스텝오버, 남길 스톡. 공구경로 미리보기와 예상 가공 시간
- 공구 라이브러리(평 엔드밀·드릴·페이스 밀, 회전수·이송), 시뮬레이션(공구 위치 슬라이더·재생)
- 포스트 처리: GRBL, LinuxCNC, Fanuc G코드

알려진 한계: URDF에는 볼·핀-슬롯·원통형 접합이 없어 고정으로 보냅니다. 평면 패턴은 OpenShape 판금 플랜지로 만든 본체만 펼칩니다. 제조는 3축 2.5D 가공만 하며(곡면 3D 가공·선반·적층 없음) 포켓은 수직으로 진입합니다. 렌더에는 유리 같은 투명 재질이 없습니다. 전자(회로도·PCB)와 애니메이션 작업공간은 없습니다.

## 구성

| 폴더 | 내용 |
|---|---|
| `engine/` | Rust 엔진(cdylib, C ABI `osc_*`): 소프트웨어 렌더러(B-rep 모서리, 면 선택), 경로 추적 렌더러, 메쉬 파일 입출력 |
| `occt/` | C++ 연결 라이브러리(`ok_*`): OpenCASCADE B-rep 형상, 숨은선 제거(도면), 2D 간격띄우기(CAM), STEP/IGES, SolveSpace 구속 해석 |
| `app/` | C# .NET 10 + Avalonia 11 UI |
| `uitest/` | Avalonia.Headless로 실제 창을 조작하는 UI 테스트 |
| `packaging/` | `build-deb.sh`: 엔진·UI 테스트를 통과하면 `dist/`에 .deb를 만듭니다 |

## 빌드

필요한 것: Rust 1.75 이상, .NET 10 SDK, g++, `dpkg-deb`. OpenCASCADE와 libslvs 개발 파일이 설치되어 있지 않으면 `packaging/fetch-occt.sh`가 Ubuntu 패키지를 받아 씁니다(관리자 권한 불필요).

```
sh packaging/build-deb.sh
```
